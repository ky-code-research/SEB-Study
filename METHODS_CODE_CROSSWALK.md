# Methods-to-code crosswalk

This crosswalk compares the candidate repository with the latest manuscript Methods and the frozen-result provenance reviewed in the restricted local environment. It is an audit aid, not a substitute for an authorized-data rerun.

Status meanings:

- **PASS** — the required method is represented in the selected code and its deterministic structure was checked.
- **REVIEW REQUIRED** — evidence is incomplete, internally inconsistent, or cannot be rerun without restricted data; no assumption of equivalence is made.
- **FAIL** — a required method is absent or contradicted by verified evidence.

## Reproduction boundary

The repository supports public inspection of variable construction, model equations, estimating equations, robust covariance, contrast algebra, FDR families, and sensitivity-analysis specifications. It does not contain the PROUD data or frozen patient-level intermediates and therefore cannot independently regenerate all manuscript numbers. If an authorized rerun changes any frozen gate, coefficient, confidence interval, P value, FDR family, OR direction, or diagnostic classification, stop and investigate rather than modifying the model to recover agreement.
